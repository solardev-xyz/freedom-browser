## 2. Remaining actual bugs and fragilities in the JS/build layer

### J1. `codesign --display --entitlements - --xml` may legitimately print nothing; the check then fails the build — LOW, fail-closed

`sign-macos-workspace-supervisor.js:14–19` requires an XML plist containing an empty `<dict/>`. The installed `codesign(1)` manual (`--entitlements`) states: "If the signature has no entitlement data, nothing is written (this is not an error)." When signing, codesign "embed[s] its contents", so a `<dict/>` file should produce an entitlements blob that displays as an empty dict, and the regex matches that. But if a codesign version normalises an empty dictionary to "no entitlement data", `stdout` is empty and the hook throws "did not produce empty entitlements". Accept both: `xml === '' || /<dict\s*\/>|<dict>\s*<\/dict>/`. Both mean "no entitlements". (Not executed here; inference from the manual.)

### J2. `--display --verbose=2` parsing relies on stderr and on the `CodeDirectory … flags=0x…(…runtime…)` and `TeamIdentifier=` line formats — LOW, fail-closed

`:20–25`, `:59–61` read `details.stderr`. codesign writes display output to stderr, so this is consistent with the tool's convention, and the test mocks it that way. All three regexes can only produce a false build **failure** if the format differs; none can produce a false acceptance (a non-matching format throws). That is the right failure direction. ### J3. State priority: `requested === 'timed_out'` or `'cancelled'` suppresses `error` even when the supervisor failed — NOTE, not a bug

`seatbelt-backend.js:714–717, 745`: a timeout/cancel that coincides with `supervisorProtocolFailed` or an abnormal S exit reports `TIMED_OUT`/`CANCELLED` with no `error`; only diagnostics carry the transport failure. ### J4. Startup-at-G edge reports `timed_out` for a startup failure — LOW (native, affects JS mapping)

`macos-supervisor.c:398–401`: when `G` arrives and either deadline has passed, the helper records `TIMED_OUT` with error 0 even when only `startup_end` (not `wall_end`) elapsed. ## 3. Native C: ownership, descriptors, last-signal-before-reap

**Ownership and reap ordering — correct.**
- The only signal syscall site is `signal_root` (`c:170–181`), gated on `spawned && owned && signal_enabled && !reaped && root > 0`; target is the direct PID until `group_verified`, then `-root`.
