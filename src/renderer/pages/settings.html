How much disk space the Swarm node keeps for pages and files you've opened, so they load faster next time. Pinned and published content doesn't count towards it.

A running node takes a new size at once, and a smaller one removes the oldest cached content straight away. Picked while the node is stopped, the size applies when it next starts, and a smaller one frees space only as new content is cached. A cache made by an older Freedom may not give the storage back right away.
