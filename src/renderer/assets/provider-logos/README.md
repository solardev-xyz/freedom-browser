# Provider logos

Original provider marks, downloaded on 2026-09-17 and bundled locally for the
provider chooser and connected-provider list. No runtime image/CDN requests.
Files are unchanged; SVGs were inspected for scripts and external references.
The marks belong to their respective providers and identify those integrations.

Brandfetch profiles were checked first. Its CDN returned
`x-bf-error: automated_traffic` and redirected downloads to its guidelines, so
these files come from the providers' own public sites instead.
