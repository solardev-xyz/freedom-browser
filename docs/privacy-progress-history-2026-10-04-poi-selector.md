**Account-bound POI preflight:** [The fixed export](https://github.com/solardev-xyz/freedom-browser/blob/3e3c1aa67e55ebfa0e4051c8148508f851cb200d/docs/railgun-poi-preflight-2026-10-04.md) derives genuine recovery capsule/journal data, observes the chain receipt/finality, verifies the TXID path in a keyless process, then acquires one late authenticated creator/completed-transaction source receipt. Root validation and account recapture follow. Its frozen private preparation grants no continuing authority; no source/root receipt survives return. New archival anchors may remain explicitly unchecked, and there is no journal writer exclusion. Both preflight paths pass ten native scenarios per operation kind. Their fixtures use structural pre-launch Shield inputs; launch-block classification does not select membership.

**Received-note POI cryptography:** [Reconstruction](https://github.com/solardev-xyz/freedom-browser/blob/3e3c1aa67e55ebfa0e4051c8148508f851cb200d/docs/railgun-poi-transact-reconstruction-2026-10-04.md) now accepts exact Transact creator data and decrypts only as receiver, with pinned WETH/value, commitment and position-derived nullifier checks. Actual foreign-sender input encryption, spend proofs, POI assembly/proving and fresh keyless verification pass for transfer and unshield; both Shield regressions also pass. Each run records 41 hashes, 13 Transact or ten Shield reconstruction refusals, 12 assembly refusals and eight altered public signals. A real sent-only note is readable by its sender but refused as our input. Membership/history remain synthetic; no creating transaction is authenticated by these fixtures. Legacy encryption is unqualified. The SDK constructs received NPKs from the current wallet, so authenticated decryption plus captured commitment comparison is essential. Private witnesses stay in the utility.

**Keyless Shield membership lookup:** [A separate utility](https://github.com/solardev-xyz/freedom-browser/blob/3e3c1aa67e55ebfa0e4051c8148508f851cb200d/docs/railgun-poi-shield-selector-2026-10-04.md) recomputes the public preimage hash and blinded commitment, with exact capsule/creator binding and observed exit. Three native vectors, including maximum tree/position, match the production pre-spend projection using structural capsules; seven refusals each and 27 source hashes pass. Altered ciphertext yields the same selector but different binding: it is bound, not decrypted or authenticated. The worker echoes the binding digest; main enforces it. Neither NPK ownership nor source event type is established. Selector and association digests remain private in memory; this diagnostic authorizes no request. All 164 related tests and lint pass.

**Proof limits remain explicit:** Separate verification uses the same pinned cryptographic implementation. The circuit does not bind checkpoint index/list metadata; changing the index still verifies but changes the payload digest. Two of fourteen earlier runs characterized flexible transfer/unshield markers; application assembly derives the marker from the matched operation. This does not establish POI-node acceptance. A transfer's POI must be accepted before its received output can supply real membership for a later spend. Enrollment/key-release integration and disclosure remain separate work.
