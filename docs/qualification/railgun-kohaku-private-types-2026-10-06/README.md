The qualified surface is the specialized `PluginInstance` and `Broadcaster<PrivateOperation, PrivateSubmissionOutcome>`. The default `Broadcaster<PrivateOperation, void>` fails with TS2322 because its promise result is incompatible. Generic `Host` and `CreatePluginFn` fail and remain unsupported. Consumers must inspect the outcome union.

The unique-symbol token brand is type-only: correctly typed object spread compiles; runtime identity checks must reject copied tokens. Concrete adapter `tailCalls` callbacks fail typing, but `tailCalls: undefined` can compile under these settings while runtime rejects any such own key. The widened actual upstream target accepts `tailCalls`; assignability therefore does not establish generic static exclusion. The separate actual upstream `PluginInstance` control rejects a number-valued internal amount with TS2344. Types alone do not authenticate authority, canonical addresses, positive amounts or note ownership.

This qualifies declaration consumers, **not the JavaScript implementation**. Candidate relative imports were resolved from the intended repository installation path; this is not portable package resolution. Native behavior and runtime authentication require separate evidence.
