# Qualification evidence

Historical Railgun qualification evidence is canonical in the dedicated
[Railgun archive](https://github.com/solardev-xyz/railgun-kohaku-adapter/tree/377c2a5d1aca18f0ed328dfdda955bd7d1ba271c/docs/freedom-qualification).
The [local index](../railgun-qualification-archive.json) pins its commit, tree,
manifest hash and original Freedom commit. The 1,165 archived records retain
original bytes, licenses, source paths and qualification limits. Relocation is
not a new runtime or native qualification.

Only 17 byte-identical public inputs remain here for current Freedom tests and
qualification tools. The local index and parity test pin each to its archive
manifest entry; they are integration fixtures, not a second canonical archive.
PPv2 and other non-Railgun qualification records remain in this directory.

The archive includes historical synthetic and local-only campaigns. It does not
supply private profiles, engine/prover binaries or general signing, transport or
funded-account authority. Historical absolute Freedom commit links remain valid;
current relative links now point to the immutable archive commit.
