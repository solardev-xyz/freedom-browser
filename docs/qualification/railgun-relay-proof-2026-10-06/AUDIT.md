# Controlled relay proof evidence scope

This archive is emitted only after the pinned whole-report validator accepts both gas cases, the runner records original qualifier exit 0 and unchanged full source/runtime/artifact inventories, and the parent observes original driver natural exit 0 without external termination. The parent observation identifies the completed independent engineering review and its scope; this is not a security audit. The exporter rechecks report, metadata and log digests, not runtime payloads or profiles.

The experiment uses fixed public disposable keys and fixed note randomness: one 1000-unit input, a 100-unit fee output first and a 900-unit self output second. Gas 0 and 1 are separate signed cases. Each has an actual 01x02 transaction proof and a separate pre-transaction POI_3x3 proof. Independent raw verification binds the ordered commitments, bound parameters and independently reconstructed public signals; each case refuses 13 mutated signals. Producer ciphertext/annotation checks establish fee annotation semantics; annotation meaning is not a separate circuit constraint.

Both producer and verifier report the exact 91-hook JavaScript guard catalog, 91 canaries and zero forbidden attempts. Four utility jobs are intentionally closed with exit 15 after their results. These observations do not establish natural utility exit, physical drainage, OS egress isolation, a native-code sandbox or Windows support. The original qualifier and parent driver exits are recorded separately.

The list path/root is unsigned and synthetic. No enrolled authority, credential loan, quote, relay request, transport, submission or live disclosure is qualified. Existing production policy and payload normalizers continue refusing this two-private-output domain. Valid raw proofs do not confer production authority or PPv2 privacy parity.

Root checks comprise 168 focused tests in five suites, natural exit, strict lint and explicit formatting of the two entry-correction files. They are not a full regression. Six r3 detached mutants ran before the entry fix. The entry-correction AST-equality check preserves proof/report logic; those six mutants were not freshly run on the final qualifier. The separate old-entry guard control distinguishes the corrected entry predicate; CHECKS.json retains this attribution.

Selected report hashes are an exact projection of the broad source inventory, not execution coverage or transitive import closure. Full inventories, raw logs and original records remain private and hash-referenced. Normalized paths and summaries are derived bytes, while report.json and EXPECTATIONS.json are copied exactly. FAILED-A.json is copied exactly from an already labelled derivative of the preserved original failed-a record; it is not the raw original failure record.

Attempt a never entered the proof fixture: default Electron startup occurred, the parent externally terminated it, and the runner refused the missing report. Its child exit 0 after external SIGTERM is not natural success. This archive retains that failure separately from fresh attempt b.

The archive does not retain public proof objects or calldata. Its assertions, counts and provenance therefore do not allow third-party cryptographic reverification from the archive alone. This compact archive is auditable evidence, not a complete standalone replay bundle. A matching source checkout, pinned runtime/artifacts and the retained runner remain external prerequisites. Offline quote/encrypted-wire qualification, durable relay-attempt handling and live protocol/service acceptance remain separate work; funded disclosures still require their own authorization.
