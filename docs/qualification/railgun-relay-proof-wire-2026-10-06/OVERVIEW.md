# Railgun: public proof-to-wire composition

A disposable native run now connects an actual Railgun transaction and pre-transaction POI proof to the selected upstream COMMON request format. The run at `41472ed4` uses fixed public test keys and synthetic history: a WETH input of 1,000 atomic units produces a 100-unit fee output followed by a 900-unit self output. It qualifies this fixture composition, not a broadcaster service or an enrolled wallet operation.

Four guarded utilities run in sequence: quote admission, proof production, wire composition and independent verification. Before proving, the fixture signs and verifies the exact synthetic quote, binds its recipient and absolute expiry, and checks the actual extracted gas helpers. A synthetic estimate of 84, the 20% buffer, gas price 1 wei and a rate of 10^18 produce a 100-unit fee. This is not a live gas estimate or evidence of sufficient service payment.

The wire utility encrypts the actual calldata and complete pre-transaction POI map through selected upstream code. Selected server code and Node GCM agree on the decrypted payload. The independent verifier receives a reconstruction from that decrypted data, checks the fee/self commitments and same-transaction POI binding, and rejects 13 altered public signals. The original proof case is not substituted for decrypted input. Each utility reports 91 installed guard hooks/canaries and zero forbidden attempts.

The original Electron child and outer driver finished naturally with exit 0, without external termination. All four utilities recorded their intentional close code 15 without escalation or peer disconnection. Root observed those processes; an independent Codex engineering review checked the recorded outcomes and provenance without rerunning cryptography or rehashing runtime binaries. This is not an external security audit or physical-drain qualification.
