# Restricted Node distribution declarations — phase-one runtime basis

This is an unpublished scratch qualification, with no repository edits or installations. It adds self-contained distribution declarations to physical copies of the frozen phase-one Node artifact. **It is not the final combined runtime artifact:** phase one accepts some acknowledgement address spellings beyond the declared `0x` shape. Root's pending runtime change must be combined and reviewed separately. No runtime or blockchain behavior was executed by this campaign.

`artifact/index.d.cts` owns all restricted types and the sole type-only PrivateOperation unique-symbol brand. `index.d.mts` explicitly forwards the three public factories and all public types through `./index.cjs`, resolving to that canonical declaration. Conditional import/require `types` entries precede their matching default runtime targets. Top-level `types` matches CJS main. No dependencies, upstream declarations, ambient module stand-ins or repository-local imports occur in the active distribution declarations. Original source contracts are included as provenance-only source files.

`prepare.py` records an exact transformation from the two pinned Freedom contracts. `TYPE-SOURCE-BASIS.json` records source, recipe, phase-one freeze and build report hashes. The phase-one `runtime.cjs` SHA-256 remains `9573d084b83fd8b2f4d7253a77826c6cf943d0b27bbeee49e25ec5d0c97287cd`; both runtime wrappers are unchanged. Of the original 20 artifact files, only package.json changes. Declaration inputs remain covered by the existing Freedom MPL-2.0 license/source inventory, supplemented by TYPE-SOURCE-BASIS and exact original contract copies. Upstream's source graph is an external qualification input, never vendored.

## Limits

The original private/snapshot research Pinned*Target aliases are excluded from distribution. Only the separate test bridge instantiates actual upstream types. Generic upstream Host/CreatePluginFn and default-void Broadcaster fail. The specialized private broadcaster retains the exact acknowledgement/unknown/recovery union; consumers must inspect it.

The unique-symbol brand is type-only: typed object spread compiles; runtime identity checks still refuse copied/foreign/replayed tokens. Host handles stay structurally empty, not newly branded. Concrete tailCalls functions fail, but tailCalls:undefined can compile with this configuration while runtime rejects any such key; widened upstream methods accept callbacks. Types do not establish canonical address length, positive amount, authority, note ownership or cryptographic correctness. Same-version duplicate package identities may be unified by TypeScript; this campaign claims one physical package's cross-entrypoint identity only.

ES2022+DOM supplies the global AbortSignal type without a new dependency. Other Node ambient-type versions, compilers, Node16/bundler consumer resolution, browsers, generic host support, JS implementation typechecking and runtime acceptance of the pending address narrowing are not qualified. The artifact retains phase one's actual runtime/module limitations. A final combined artifact will require fresh pins and checks appropriate to its final changes.
