# Combined restricted Node prototype

This unpublished artifact joins the corrected phase-two runtime with the reviewed portable declarations. `source/COMBINE.py` verifies the two frozen lane inventories, reproduces the exact declaration/manifest transform, and assembles a fresh output deterministically. Run `python3 combine.py RUNTIME_LANE TYPE_LANE FRESH_OUTPUT` using preserved reviewed lanes. There is no installation, runtime execution or source compilation in that assembly step.

`BUILD-RECIPE.cjs` and `source/SOURCE-BASIS.json` reproduce the runtime phase only. That recipe emits its pre-type package manifest; it does not reproduce this final manifest alone. `provenance/runtime-phase-build-report.json` is historical runtime-build input evidence. `provenance/historical-type-lane-*` retains the original phase-one-based type recipe/basis for provenance, not the final runtime identity. The combiner includes the effective declaration transform without requiring execution of that historical hardcoded recipe. `TYPE-SOURCE-BASIS.json` records the corrected final runtime, manifest and unchanged declaration joins. The external COMBINED-REPORT and ARTIFACT-INVENTORY identify all final bytes; no phase report is asserted to hash the final manifest.

Existing full license texts and exact Freedom runtime sources are retained. The two original Freedom MPL-2.0 contract sources are included under source/scripts/fixtures; their derived declarations remain covered by licenses/freedom/LICENSE. There are no new bundled third-party dependencies or upstream source files. Build tools and compiler are not shipped runtime dependencies. This inventory is not distribution approval.

Use one physical package for both CJS and ESM so identity maps and the type-only operation brand share their canonical modules. Same host across independent copies/realms is unsupported. Caller-owned trusted hosts supply authority and policy; recipient syntax is not self-recipient authorization. Crypto, wallet/network services, chain eligibility, live receipts and generic upstream Host are not qualified. Compiler conformance is separate from runtime behavior and does not typecheck JavaScript. The package is private, restricted to pinned Node24.18.1 and the documented Sepolia outcome/input surface, not a released chain-agnostic wallet SDK.
