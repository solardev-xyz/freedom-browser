# Restricted Railgun Node prototype: audit evidence

This archive preserves an **unpublished, restricted Node prototype** and its completed qualification. It is inspectable evidence, not a releasable package or self-contained reproduction environment. The exact 30-file package is recorded by the [original artifact inventory](combined/ARTIFACT-INVENTORY.json.txt); each artifact file appears once under `artifact/` with a `.txt` suffix. The runtime, declarations, covered source and complete accompanying license texts are included. The runtime remains byte-exact SHA-256 `61add3033264bb4f2e1a1a402bc861a7cff1f173f8de1df1ea909e1b0fe85f39`; canonical declarations remain `a40a45e1ba0cc5d1eb6d12b81203a9b175011cf6987d78a6791daec1a475428c` and ESM forwarding declarations `f1ab1733928832362add1f1217814c591367f8f798dd2a2ce9293d0555fb6edc`.

The three public factories provide snapshot reads, private transfer/unshield preparation and a result-bearing broadcaster through trusted application host callbacks. They preserve host-relative data and one-use runtime token identity. Both CJS and ESM wrappers share one runtime and one declaration brand. The genuine Freedom host, account authority, storage, wallet engine and prover are excluded. This prototype is not a generic Kohaku Host implementation, live chain qualification, browser package or cryptographic audit.

## Limits and notable controls

Runtime tests use independent in-memory trusted hosts. They do not authenticate ownership, self-recipient policy, POI, cryptographic proofs or network receipts. Sticky network/process/root-import traps cover the tested entry points; they are not OS egress isolation. Applications must not share one host across separate physical artifact copies. Successful lowercase/checksummed acknowledged addresses preserve original outcome identity; unsupported ICAP/unprefixed/malformed forms become an unknown result. Outcome consumers must handle acknowledged, unknown and recovery-required states.

PrivateOperation's unique-symbol brand is type-only: a typed spread can compile, while runtime identity refuses copied tokens. Concrete adapter tailCalls callbacks fail typing, but an explicitly undefined key can compile under these settings while runtime rejects the key; the widened actual upstream method type accepts callbacks. Generic upstream Host/CreatePluginFn and default-void Broadcaster remain unsupported. The misrouted ESM types mutation still typechecks, but the required entry-declaration graph detects it; this is not reported as a compiler diagnostic. The first upstream type harness's overstrict graph assumption is preserved in its original freeze and explained in the historical README; the final harness explicitly loads the actual bridge.

This archive adds no tests, compiler run, runtime/native execution, profile access, installation or publication. Existing runtime/type observations retain their original attribution. The declarations were checked as consumer contracts, not as JavaScript implementation typechecking. Production release, wider compiler/platform/global-library support and live wallet integration remain separate work.
