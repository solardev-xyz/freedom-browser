## Scope and limits

These are explicit specialized trusted-host contracts. This is not generic Kohaku Host/CreatePluginFn conformance, an implementation-JavaScript typecheck, proof that declarations describe every runtime path, a browser artifact, or wallet/native/live-funds qualification. There are no fixed Freedom hosts or wallet authorities in the artifact. Runtime consumer evidence is a separate lane; this lane executes only compiler/harness code, never generated runtime functions or type examples.

The distinct operation brands are phantom type-only identities. A structurally spread typed token can still compile, and real runtime authority depends on original identity and one-use checks. Hex templates do not prove address length/checksum; amount types do not prove positive values; host handles do not statically prove authority. The public acknowledgement has string value, while the private acknowledged value remains literal '0'; unknown/recovery private outcomes are not public fulfilled results. Promise rejection reasons are handled separately (unknown in catch) and cannot be expressed by the fulfilled Promise type.

Concrete private methods exclude tailCalls, but the widened actual upstream method accepts them; this declaration assignability limitation is not support. No claim that arbitrary widened asset views preserve the native-only restriction is made. Historical broader negative matrices, default-void Broadcaster failure and earlier source evidence remain historical and are not relabelled as rerun here.

The actual upstream bridge uses installed ox 0.14.45, @scure/bip32 1.4.0 and @scure/bip39 2.4.0. Kohaku provider requests ox ^0.12.0; this is an explicit dependency mismatch, not an upstream lockfile build. Source graph reads are hashed but not executed. No upstream source or compiler/dependency payload is vendored into this artifact. Runtime dependencies already bundled in the approved runtime retain their existing licenses and source records; added contracts are Freedom-owned and covered by the included Freedom MPL-2.0 license. The pinned Kohaku packages have no discovered package license field or root/package license file; no legal conclusion or upstream redistribution permission is inferred.

The artifact is a local prototype, not a released or published package. Assembly/source records include local scratch and repository paths and would require an explicit mapped publication transformation before public archival. No root files, dependencies, accounts, network services, or funded profiles were changed or accessed in this lane.
