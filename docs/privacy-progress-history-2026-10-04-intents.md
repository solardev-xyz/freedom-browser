**Prepared proof persistence:** [The account-owned store](https://github.com/solardev-xyz/freedom-browser/blob/02386f255e30bcfbe0476bf53b27d696628dfcfc/docs/railgun-poi-intent-store-2026-10-04.md) retains a genuine local POI proof through encrypted store/account reopen. Its only write path authenticates the live proof registry, binds the payload and compares account recovery before and after persistence. Exact payload/binding data live in a separately keyed encrypted file with inventory and manifest floor checks. It exposes no raw writer, sender, attempt, retry, renderer or IPC API.

Only prepared state is supported. Identical preparations do not write; a newer genuine proof can replace an unsent preparation for the same capsule/selector, up to four revisions. Earlier unsent payloads are not retained. Limits are 32 records/sequence 128, with space and three transitions reserved per entry for the later attempt and observations. Future attempted state requires a newer schema and an authorization-bound handoff.

Close revokes immediately and wipes key buffers; ownership remains held until initialization, pending storage callbacks and recovery windows drain. Caller cancellation leaves healthy storage usable. Integrity/floor/readback failures close it; reopening must reattest. A refusal after a committed write can leave a prepared record. A floor catches a document restored below its sequence, but cannot detect a coordinated whole-profile rollback. Strict archive equality currently requires renewed proof history if archival occurs between proving and preparation.
