# Ordinary submission classification and retained history

The shared nonce journal initially recorded ordinary sends without a PPv2 intent. Claude's follow-up review found that this caused more than a capacity problem: every intent-less record makes PPv2's exit reservations refuse notes, balances, withdrawal selection and emergency exits. Archiving that record without classification would preserve the lockout. No funded profile was used during these changes.

New ordinary sends now retain facts derived from their signed transaction: target address, four-byte selector (or null), transaction type, and an explicitly **unverified RPC** observation that the sender has no code. The selector is informational and is not used to decide safety. These facts are stored inside the encrypted public-submission journal, never as plaintext diagnostics. Classification is evaluated against the current deployment pins whenever PPv2 reads reservations.

For enrolled Sepolia accounts, the ordinary route refuses all twelve pinned protocol, implementation and verifier addresses. It also refuses contract creation, transaction types other than 0/1/2, and explicitly supplied authorization lists. These checks run before signing and again on the signed bytes before an attempt is recorded. The ordinary network must return exactly `0x` for `eth_getCode(sender, pending)` immediately before signing and again afterward; malformed responses, delegation designators, code and read failures stop the send without recording an attempt. A long hardware-wallet prompt therefore cannot reuse the earlier code observation. The existing nonce lease, balance check, signed-intent comparison and one-use handoff remain required.

This policy relies on the reviewed PPv2 source: `PoolVault.sol:208` at SDK/contracts revision `fe0244e3f14110efd83db02c60c96517dea9cd5a` requires `msg.sender == proof.ownerAddress()` for ragequit. A normal call to another contract reaches the pool with that contract as caller, not the undelegated wallet. PPv2 preflight separately checks the pinned proxy implementation. The sender-code check is defence in depth against external EIP-7702 delegation: Freedom's ordinary route cannot sign type-4 transactions, and its message-signing APIs do not expose the raw authorization-signing domain. RPC observations are not verified chain state; externally installed delegation after the observation, actions on other devices and dishonest RPC answers remain outside this guarantee. This policy does not claim to classify all effects of arbitrary contract calls or identify all external private spends.

Known ordinary sends no longer disable PPv2 notes or balance inspection. The durable unresolved-send gate still blocks further submissions until explicit reconciliation. A future pin that includes a stored target makes that record require recovery again. Unknown legacy records are never relabeled automatically; in particular, any intent-less ordinary records written by `acfef6e0` remain unknown. There is currently no automatic migration or release for them.

Schema 4 stores these facts and preserves them in the permanent archive. Every initialization or journal mutation writes schema 4, including observation/acknowledgment updates to a journal with only private records. This keeps a single canonical write format. Older builds reject schema 4; downgrading requires a reviewed migration, not deleting the journal. Classified records may join the existing strict-prefix archival flow only after resolution, at least 24 hours, matching finalized-block observations before and after explicit review, and acceptance that archived evidence will no longer be revalidated. Hashes, nonces and classification facts remain. Unknown legacy records at the head still prevent archival of all later records. Capacity remains bounded at 64 live plus 1,024 archived records for an account; this is not unlimited history.

The policy, coordination, journals and reservation logic remain main-process wallet responsibilities. No renderer API, product flow, dependencies or funded-profile state were changed.
