- Updated bundled nodes:
  - [Ant](https://github.com/freedom-hq/ant) 0.5.61 to 0.5.77: the Swarm card in the Nodes tab shows the node wallet's real xDAI and xBZZ instead of 0 when the chequebook needs no top-up, and a balance the node could not read shows as unknown instead of 0; pages inside a Swarm site load on a fresh node even when the site's root is only stored as a replica; a site published behind a feed, such as a live stream's playlist, is read from the last update the node found instead of from the feed's start, and a newest update that is slow to fetch shows on the next read instead of about 20 seconds later, so a live stream keeps playing; paid uploads are faster; a new chequebook no longer starts out looking spent; a node that can't yet tell whether a feed is empty says so instead of reporting it empty, so a first write can't overwrite an existing feed; publishing finishes sooner, as a file's replicas are sent alongside its other pieces instead of after them and a piece that first lands outside its neighbourhood is retried at once instead of after a 2.5 second wait; and 0.5.71's security fixes, ported from bee 2.8.3: a crafted upload can no longer freeze the node while it repairs missing pieces, forged replicas of a page are rejected instead of being cached or blocking its recovery, a damaged postage stamp file no longer stops the node from starting, a damaged cheque record is set aside instead of restarting cheques from zero, and peers can no longer make the node hold ever more memory with made-up peer addresses or with transfers that announce data and never send it
