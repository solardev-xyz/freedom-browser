- Freedom Agent — browsing and project work with your connected AI model ([#457](https://github.com/solardev-xyz/freedom-browser/pull/457)):
  - Agent can make a private draft link instead of publishing: the upload is encrypted, and the approval says plainly that anyone with the link can read it and that the encrypted data still stays on the public network for good. A draft never gets a stable address or a name, and publishing it publicly later is a separate approval ([#741](https://github.com/solardev-xyz/freedom-browser/issues/741))
  - Agent can publish a site to a stable address owned by your Swarm identity, so later fixes keep the same link; the approval says older versions stay retrievable by anyone who has their link while their postage lasts ([#741](https://github.com/solardev-xyz/freedom-browser/issues/741))
  - The publish approval shows which postage batch is used, roughly how much of it the upload takes and how long it has left, and warns when it is about to expire ([#741](https://github.com/solardev-xyz/freedom-browser/issues/741))
  - The pre-publish check also lists scripts, stylesheets, images and requests loaded from other sites, and forms that send to other sites, as warnings; new Agent sites start from a template with a restrictive Content Security Policy ([#741](https://github.com/solardev-xyz/freedom-browser/issues/741))
